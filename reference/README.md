# Visual reference

Screenshots of the **real, rendered** Claude Design mockup — not our
reimplementation. Use these as the source of truth for how each section is
actually supposed to look; the mockup's raw HTML/CSS alone is not reliable
enough to eyeball since a lot of it only resolves once the prototype's React
runtime renders it (decorative flower illustrations, computed layouts,
gradients spread across many small `<img>`/CSS rules).

Regenerate after every `design/` re-export with `scripts/capture-reference.mjs`
(see the header comment in that file for exact steps).
