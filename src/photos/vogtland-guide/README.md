# Vogtland-Guide — jeder Ordner ist ein eigener Ausflugstipp

Genau wie bei "Unsere Geschichte" und "Ablauf": jeder Unterordner hier wird
automatisch zu einer Postkarte im Vogtland-Guide. **Neuer Ordner = neuer
Tipp**, ohne Code — die Buchstaben-Markierung (A, B, C, …) auf den Karten
wird automatisch vergeben.

**Neuen Tipp hinzufügen:**
1. Neuen Ordner anlegen, z. B. `vogtland-guide/5-drachenfelsen/` — die
   Zahl vorn bestimmt nur die Reihenfolge (wird nirgends angezeigt).
2. Darin eine `entry.md` mit den Feldern unten.
3. Ein Foto reinlegen — beliebiger Dateiname.

**`entry.md`-Felder:**

| Feld | Pflicht? | Bedeutung |
|---|---|---|
| `titel` | ja | Die verspielte Überschrift, z. B. "für das Pflichtfoto" |
| `ort` | ja | Der eigentliche Ortsname, z. B. "Göltzschtalbrücke" |
| `distanz` | nein | z. B. "15 Min · größte Ziegelsteinbrücke der Welt" |
| `karte` | nein | Suchbegriff für den "Route"-Link (Google Maps) |

Danach folgt optional ein Absatz Fließtext — erscheint im aufklappbaren
"mehr"-Bereich der Karte.

Übersetzung wie überall: `---en---`/`---sv---` darunter, gleiche Felder,
fehlt eine, wird Deutsch angezeigt.
